## ADDED Requirements

### Requirement: Реестр имён иконок (SF Symbols) как единый источник
Слой дизайн-системы SHALL предоставлять именованный реестр `Icons` имён SF Symbols
(семантические, сгруппированные константы). Вью SHALL получать имена символов из этого
реестра; сырые строковые имена SF Symbols SHALL отсутствовать в аргументах
`systemName:`/`systemImage:` во вью (`Sources/ShortlinksApp/Views`, `MainView.swift`).
Смена иконки для роли SHALL выполняться правкой реестра без изменений во вью.

#### Scenario: Во вью нет сырых имён символов
- **WHEN** выполняется поиск строковых литералов в аргументах `systemName:`/`systemImage:`
  по каталогу вью
- **THEN** совпадений нет — имена идут через реестр `Icons`

#### Scenario: Смена иконки в одном месте
- **WHEN** для роли (например «новая ссылка») меняется имя символа в реестре `Icons`
- **THEN** иконка меняется во всех местах использования без правок во вью
