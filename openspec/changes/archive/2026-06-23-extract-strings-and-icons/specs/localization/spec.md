## ADDED Requirements

### Requirement: Единый локализуемый источник пользовательских строк
Все пользовательские строки приложения, ядра и CLI SHALL браться из локализуемого
ресурсного слоя (String Catalog `Localizable.xcstrings`) через типизированный реестр
`Strings` (доступ вида `Strings.<name>` поверх `String(localized:)`). Сырые
пользовательские строковые литералы SHALL отсутствовать во вью
(`Sources/ShortlinksApp/Views`, `MainView.swift`, тосты `AppModel`), в презентационных
хелперах ядра (`Format`, `Scheme`) и в текстах CLI (`abstract`/`help`/вывод). Технические
литералы, не показываемые пользователю (схемы `sl://`/`https://`, ключи, идентификаторы
типов, значения фильтров/TTL), НЕ считаются пользовательскими строками и под требование
не подпадают.

#### Scenario: Во вью нет сырых пользовательских строк
- **WHEN** во вью отображается заголовок, подпись или текст кнопки
- **THEN** используется `Strings.<...>`, а не строковый литерал по месту

#### Scenario: Строка меняется в одном месте
- **WHEN** правится текст в реестре `Strings`/каталоге
- **THEN** он меняется во всех местах использования без правок во вью/CLI/ядре

### Requirement: Фолбэк на язык-источник и добавление языков без изменений кода
Реестр строк SHALL хранить русский текст как значение по умолчанию языка-источника
(`String(localized:defaultValue:)`), чтобы при отсутствии перевода интерфейс отображался
по-русски идентично прежнему. Добавление нового языка SHALL выполняться только правкой
ресурсов (каталога), без изменений в коде вью/ядра/CLI.

#### Scenario: Нет перевода — русский как прежде
- **WHEN** в каталоге нет перевода для активной локали
- **THEN** отображается русский текст из `defaultValue`, совпадающий с домиграционным

#### Scenario: Новый язык без правок кода
- **WHEN** в каталог добавляется перевод на новый язык
- **THEN** строки переключаются на него без изменений в исходном коде

### Requirement: Склонения через правила каталога
Числовые склонения SHALL задаваться plural-вариациями String Catalog (категории CLDR
one/few/many/other) — формы «переход/перехода/переходов», «час/часа/часов»,
«день/дня/дней», «ссылку/ссылки/ссылок» и т.п. — а не ручной сборкой строки по числу.
Перевод на язык с иными правилами множественного числа SHALL не требовать изменений кода.

#### Scenario: Корректная форма по числу (русский)
- **WHEN** отображается счётчик переходов для 1, 2 и 5
- **THEN** выводится «1 переход», «2 перехода», «5 переходов» соответственно

#### Scenario: Правила другого языка
- **WHEN** в каталог добавляется перевод на язык с другими категориями множественного числа
- **THEN** нужная форма выбирается правилами каталога без правок кода

### Requirement: Охват приложения, ядра и встроенного CLI
Локализация SHALL покрывать GUI приложения, презентационные строки `ShortlinksCore`
(`Format`/`Scheme`) и тексты `shortlinks-cli` (`abstract`/`help`/вывод/`ValidationError`).
Встроенный в бандл приложения CLI SHALL резолвить локализацию из ресурсов приложения
(`Contents/Resources`); при отдельной (standalone) сборке CLI допускается фолбэк на
язык-источник.

#### Scenario: Локализуемый текст CLI
- **WHEN** запрашивается `shortlinks --help` у встроенного в приложение CLI
- **THEN** тексты берутся из общего каталога (с русским как языком-источником), а не из
  захардкоженных по месту литералов

#### Scenario: Standalone-CLI не падает без ресурсов
- **WHEN** CLI собран отдельно и каталог недоступен
- **THEN** выводится русский текст из `defaultValue`, выполнение не прерывается

### Requirement: Выбор языка CLI по локали и переменным окружения
CLI SHALL выбирать язык по приоритету: флаг `--lang`, затем POSIX-переменные
`LC_ALL`/`LC_MESSAGES`/`LANG`, затем системные предпочтения языка (`AppleLanguages`), затем
язык-источник. Значения `C`/`POSIX` и нераспознанные коды SHALL трактоваться как отсутствие
локали (фолбэк на язык-источник) без прерывания выполнения. GUI SHALL следовать системной
локали без переменных окружения и флагов.

#### Scenario: Флаг важнее переменных окружения
- **WHEN** одновременно заданы `--lang` и `LANG`
- **THEN** используется язык из `--lang`

#### Scenario: C/POSIX — фолбэк на язык-источник
- **WHEN** выполняется `LANG=C shortlinks list`
- **THEN** выводится русский текст (язык-источник), выполнение не прерывается

#### Scenario: GUI следует системе
- **WHEN** в системе изменён список предпочитаемых языков
- **THEN** приложение следует ему без флагов/переменных окружения

### Requirement: Паритет поведения и текста
Вынос строк в ресурсы SHALL быть рефактором без изменения наблюдаемого поведения и
видимого текста: отображаемые русские строки SHALL посимвольно совпадать с
домиграционными, доменная логика не меняется. Существующие тесты `ShortlinksCoreTests`
SHALL оставаться зелёными.

#### Scenario: Текст не изменился
- **WHEN** экран или вывод CLI отрисованы после миграции на ресурсы
- **THEN** видимый русский текст совпадает с домиграционным

#### Scenario: Ядро остаётся зелёным
- **WHEN** прогоняются `ShortlinksCoreTests`
- **THEN** они проходят — изменения ограничены источником строк
