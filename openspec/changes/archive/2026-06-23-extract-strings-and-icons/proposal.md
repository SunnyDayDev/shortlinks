## Why

Все пользовательские строки сейчас захардкожены литералами по месту (вью, `Format.swift`,
`Scheme.swift`, `ShortlinksCLI.swift`) — ~110 строк на русском, разбросанных по трём
таргетам. Это блокирует перевод приложения на другие языки (заявленная цель) и
противоречит принципу дизайн-системы «во вью нет магических литералов» (цвета, шрифты,
отступы уже вынесены в токены — строки и имена SF Symbols нет). Аналогично имена иконок
(SF Symbols) дублируются строковыми литералами по вью, без единого реестра.

## What Changes

- Все пользовательские строки выносятся в **типизированный реестр `Strings`** (вложенные
  namespace по экранам/доменам) поверх **String Catalog** (`Localizable.xcstrings`).
  Доступ — `Strings.<name>` через `String(localized:)`; русский текст остаётся в коде как
  `defaultValue` (источник/dev-язык), каталог — поверхность для будущих переводов.
- Охват — **приложение + ShortlinksCore + CLI**: вью, презентационные строки
  `Format`/`Scheme`, тосты `AppModel`, а также `abstract`/`help`/вывод `shortlinks-cli`.
- Русское склонение (3 формы) переводится с ручного `Format.plural` на **plural-вариации
  String Catalog** (CLDR-категории one/few/many/other), чтобы перевод на языки с другими
  правилами не требовал правок кода.
- Встроенный в бандл CLI резолвит локализацию через **bundle-локатор** (ресурсы берутся из
  `Contents/Resources` приложения); при standalone-сборке CLI — фолбэк на `defaultValue`.
- Имена SF Symbols выносятся в **реестр иконок `Icons`** (семантические, сгруппированные
  константы) в слое дизайн-системы; вью перестают нести сырые строковые имена символов.
- `project.yml` дополняется ресурсом каталога и списком локализаций (dev-регион `ru`);
  обновляются конвенции в `CLAUDE.md`.
- Наблюдаемое поведение и внешний вид **не меняются** — это рефактор источника строк/иконок
  (русский текст идентичен прежнему).

## Capabilities

### New Capabilities
- `localization`: все пользовательские строки приложения, ядра и CLI берутся из
  локализуемого ресурсного слоя (String Catalog) через типизированные аксессоры, с
  поддержкой склонений и фолбэком на язык-источник; добавление новых языков не требует
  изменений в коде.

### Modified Capabilities
- `design-system`: добавляется требование о реестре имён иконок (SF Symbols) как едином
  источнике — вью не содержат сырых строковых имён символов, по аналогии с уже
  действующими требованиями «во вью нет сырых цветов/кеглей/магических чисел».

## Impact

- **ShortlinksCore**: новый публичный `Strings` (реестр строк) и `Bundle`-локатор
  локализации; `Format.swift` (склонения → каталог, лейблы статусов/типов через `Strings`),
  `Scheme.swift` (лейблы целей через `Strings`).
- **ShortlinksApp**: новый `Localizable.xcstrings` (в Resources таргета) и реестр `Icons`
  в `DesignSystem/`; все `Views/*`, `AppModel.swift`, `IconTile`/`TargetIcon`-вызовы
  переводятся на `Strings.*`/`Icons.*`.
- **shortlinks-cli**: `ShortlinksCLI.swift` — `abstract`/`help`/`print`/`ValidationError`
  через `Strings`.
- **Сборка**: `project.yml` (ресурс каталога, `CFBundleLocalizations`/dev-регион),
  `xcodegen generate`. Зависимостей не добавляется (только Foundation/SwiftUI).
- **Тесты**: `ShortlinksCoreTests` дополняются проверками склонений/локализации; остальное
  поведение и существующие тесты — без регресса.
