## Why

При открытии `sl://link/<slug>` приложение ведёт себя как обычное (`LSUIElement:
false`): в Dock появляется иконка, фокус перехватывается. Для фонового перехода
(многоразовая активная ссылка без пароля) это лишний визуальный шум — пользователь
ждёт «тихого» открытия цели, как у переходника ссылок, а не запуска полноценного
приложения.

Полностью «не запускать приложение» при открытии `sl://` нельзя: macOS резолвит
кастомную схему через LaunchServices и обязана запустить **какой-то** процесс-обработчик.
Поэтому цель — убрать видимость запуска (иконку в Dock, перехват фокуса), а сам факт
кратковременного запуска фонового процесса зафиксировать в документации как
неустранимое ограничение платформы.

## What Changes

- Приложение становится **фоновым агентом** (`LSUIElement: true` / `ActivationPolicy
  .accessory`): постоянной иконки в Dock больше нет, оно живёт в меню-баре.
- При фоновом переходе (активная многоразовая ссылка без пароля и без режима
  подтверждения) открытие цели происходит **без иконки в Dock и без вывода окна**.
- Когда нужно взаимодействие (пароль, ненайденная/заблокированная ссылка, режим
  подтверждения), приложение **временно** повышается до `.regular`, показывает окно
  оверлея и активируется; после завершения перехода возвращается в `.accessory`.
- Документируется неустранимая причина, по которой обработчик схемы обязан быть
  запускаемым приложением (нельзя обработать `sl://` вовсе без запуска процесса), —
  в `CLAUDE.md` и в design этого изменения.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `link-redirection`: добавляется требование «тихого» фонового открытия — обработка
  `sl://` без иконки в Dock и без вывода окна, с временным повышением политики
  активации только когда требуется UI.

## Impact

- `Sources/ShortlinksApp/ShortlinksApp.swift` — логика `AppDelegate.application(_:open:)`,
  переключение `NSApp.setActivationPolicy`.
- `Sources/ShortlinksApp/AppModel.swift` — точки, требующие/освобождающие UI
  (возврат в `.accessory` после закрытия оверлея).
- `project.yml` (`LSUIElement`) + `Sources/ShortlinksApp/Info.plist` — регенерация через
  `xcodegen generate`.
- `CLAUDE.md` — фиксация ограничения и нового режима активации.
- Спека `openspec/specs/link-redirection` — обновляется через `/opsx:sync`.
