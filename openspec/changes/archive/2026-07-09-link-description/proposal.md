## Why

Сейчас в списке видны только `slug` и цель (`target`) — а для защищённой ссылки цель
ещё и замаскирована. По короткому адресу и «голому» URL/пути трудно вспомнить, куда
ссылка ведёт и что откроется при переходе. Небольшое человекочитаемое описание решает
это: подпись «зачем эта ссылка», которую видно в списке, в карточке и на экране
подтверждения перехода.

## What Changes

- Ссылка получает необязательное поле **описание** (`note`) — свободный текст с
  человекочитаемой подписью «куда ведёт / что откроется».
- **Форма создания** (приложение): новое необязательное многострочное поле «Описание».
- **CLI**: у команды `add` появляется опция `--note`; `list` показывает описание, когда
  оно задано.
- **Карточка деталей**: описание выводится отдельной строкой (когда задано).
- **Список ссылок**: когда описание задано, строка показывает **его вместо цели**
  (усечённо); без описания — цель, как прежде. Без дополнительной иконки.
- **Поиск**: описание участвует в поиске наравне со slug, целью и тегами.
- **Оверлей подтверждения перехода**: описание показывается (когда задано), помогая
  понять, что откроется, — в том числе для защищённой ссылки (описание — авторская
  подпись, а не секретная цель, поэтому не маскируется).
- **Хранение**: `note` добавляется в запись `links.json` как необязательное поле;
  старые файлы без него читаются без ошибок (обратная совместимость).
- **Дизайн-файл** `design/shortlinks.pen` обновляется: поле «Описание» на экране
  создания, строка «Описание» в карточке деталей, описание вместо цели в строке списка и
  описание в оверлее перехода (из существующих токенов/компонентов).

Описание в этом изменении задаётся **при создании** (форма и CLI) и не редактируется
после — как и `target`, теги и пароль (правка существующих полей — отдельное изменение).

### Modified Capabilities
- `link-management`: у ссылки появляется необязательное поле `note`; оно задаётся при
  создании, хранится в `links.json` (с обратной совместимостью), участвует в поиске и
  отображается в списке и карточке деталей.
- `cli-interface`: `add` получает опцию `--note`; `list` выводит описание, когда задано.
- `link-redirection`: экран подтверждения перехода показывает описание ссылки, когда оно
  задано (не маскируется для защищённых ссылок).

## Impact

- **Код (ShortlinksCore)**: `Link` (поле `note`, параметр `Link.make`), `Strings`
  (новые строки). `ConflictMerge` не меняется — слияние идёт по `id` целой записью,
  `note` едет вместе с победившей версией.
- **Код (ShortlinksApp)**: `CreateForm`/`AppModel` (поле формы, передача в `Link.make`,
  поиск по `note`), `CreateSheet` (поле ввода), `LinkDetailView` (строка), `LinkListView`
  (подпись строки), `RedirectOverlay` (подпись).
- **Код (shortlinks-cli)**: `Add` (`--note`), `ListCmd` (вывод описания).
- **Ресурсы**: новые ключи в `Localizable.xcstrings` (источник — русский).
- **Дизайн**: `design/shortlinks.pen` — поле на экране создания и строка в карточке.
- **Тесты**: `ShortlinksCoreTests` — кодирование/декодирование `note`, обратная
  совместимость, нормализация пустого описания. Новые тест-файлы требуют `xcodegen generate`.
- **Хранилище**: формат `links.json` расширяется аддитивно; миграция не нужна.
