## ADDED Requirements

### Requirement: Открытие окна по активации приложения
Приложение SHALL показывать главное окно, когда пользователь активирует приложение
не через `sl://`: при обычном запуске (двойной клик по иконке, Spotlight, Launchpad) и
при повторной активации уже запущенного агента (reopen — клик по иконке). Запуск ради
открытия `sl://` (когда вызывается `application(_:open:)`) SHALL оставаться тихим и
**не** показывать окно.

#### Scenario: Запуск кликом по иконке
- **WHEN** пользователь запускает приложение двойным кликом по иконке (или из Spotlight/Launchpad), без открытия `sl://`
- **THEN** показывается главное окно, приложение активируется

#### Scenario: Повторная активация запущенного агента
- **WHEN** приложение уже работает в фоне и пользователь снова кликает по его иконке
- **THEN** главное окно показывается/поднимается поверх

#### Scenario: Запуск ради sl:// остаётся тихим
- **WHEN** приложение запускается для открытия `sl://link/<slug>` фонового перехода
- **THEN** окно не показывается (тихий фоновый сценарий не нарушается)
