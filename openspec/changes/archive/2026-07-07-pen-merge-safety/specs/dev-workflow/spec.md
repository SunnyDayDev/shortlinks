# dev-workflow — Delta Spec

## MODIFIED Requirements

### Requirement: Синхронизация дизайн-файла при изменениях UI
Pull Request с изменением UI приложения SHALL синхронизировать дизайн-файл: PR,
меняющий внешний вид экранов, компонентов или токенов в `Sources/ShortlinksApp/`,
включает соответствующее обновление `design/shortlinks.pen` — либо явное указание в
описании PR, что визуальных изменений нет (например, рефактор без изменения внешнего
вида). Обновление дизайн-файла SHALL соответствовать дизайн-системе (использовать её
переменные и мастера-компоненты). Правило соблюдается по договорённости и проверяется
на ревью (техническое принуждение невозможно: branch protection недоступна). Файл — это
plain JSON, поэтому дифф дизайн-файла читаем на ревью, а параллельные правки допустимо
сливать по модели безопасного слияния (см. capability `design-file`).

#### Scenario: PR с новым экраном
- **WHEN** открывается PR, добавляющий или визуально меняющий экран приложения
- **THEN** в PR входит обновлённый `design/shortlinks.pen` с соответствующим фреймом,
  собранным из компонентов дизайн-системы

#### Scenario: PR с рефактором без визуальных изменений
- **WHEN** открывается PR, затрагивающий код вью, но не меняющий внешний вид
- **THEN** дизайн-файл не обновляется, а в описании PR явно указано, что визуальных
  изменений нет

#### Scenario: Ревью замечает рассинхрон
- **WHEN** на ревью PR внешний вид изменён, но дизайн-файл не обновлён и оговорки в
  описании нет
- **THEN** PR не мержится до обновления дизайн-файла или явной оговорки
