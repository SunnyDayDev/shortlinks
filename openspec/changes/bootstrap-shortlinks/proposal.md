## Why

Нужен локальный сервис коротких ссылок на Mac: регистрация одноразовых и
постоянных ссылок и их обработка, с синхронизацией между устройствами. Готов
детальный макет из Claude Design (`_design/Одноразовые ссылки.dc.html`) и
утверждённый план — это первый, фундаментальный заход: с нуля разворачиваем проект,
рабочее окружение (git/GitHub, настройки агента) и базовую функциональность.

## What Changes

- **Скаффолд проекта:** Xcode-проект через XcodeGen (`project.yml`) с тремя
  таргетами — общий `ShortlinksCore`, SwiftUI-приложение (меню-бар + окно), CLI.
- **Управление ссылками:** модель ссылки, создание одноразовых/многоразовых, slug,
  срок действия (1ч/24ч/7д/∞), теги, опциональный пароль, список с фильтрами и
  поиском, удаление; экраны UI по макету.
- **Обработка `sl://`:** регистрация приложения обработчиком кастомной схемы
  `sl://link/<slug>` в macOS, поток подтверждения перехода (ready/blocked/consumed),
  «сгорание» одноразовой после первого перехода.
- **Синхронизация через iCloud Drive:** опциональное хранение всех ссылок в одном
  JSON-файле в папке iCloud Drive (бесплатный Apple ID, без entitlements),
  координированный доступ и разрешение конфликтов слиянием по `id` ссылки.
- **CLI:** команды `add` / `list` / `rm` / `open` / `resolve` поверх общего ядра.
- **Окружение разработки:** инициализация git, создание репозитория GitHub, `.gitignore`,
  `README`, `CLAUDE.md` и настройка окружения агента (навыки/инструкции проекта).
- Поведение одноразовой ссылки по умолчанию — пометка «сгорела» (как в макете), с
  переключателем «Удалять после перехода». Текст приватности приведён к opt-in iCloud.

## Capabilities

### New Capabilities
- `link-management`: доменная модель ссылки и операции над ней — создание
  (once/reuse), генерация и валидация slug, срок действия, теги, пароль, хранение,
  список с фильтрами/поиском, удаление; UI-оболочка (меню-бар + окно).
- `link-redirection`: регистрация и обработка схемы `sl://link/<slug>`, поток
  подтверждения перехода, потребление одноразовой ссылки, парольный гейт.
- `icloud-sync`: опциональная синхронизация хранилища через файлы в iCloud Drive,
  наблюдение за внешними изменениями и разрешение конфликтов.
- `cli-interface`: командный интерфейс терминала поверх общего ядра.

## Impact

- **Новый код:** `Sources/ShortlinksCore`, `Sources/ShortlinksApp`,
  `Sources/shortlinks-cli`, `project.yml`, `Sources/ShortlinksApp/Info.plist`.
- **Хранилище:** единый JSON-файл `~/Library/Mobile Documents/com~apple~CloudDocs/
  Shortlinks/links.json` (fallback — `~/Library/Application Support/Shortlinks/links.json`).
- **Системная интеграция:** Launch Services (схема `sl://`),
  `LSSetDefaultHandlerForURLScheme`, `NSWorkspace.open` для целей.
- **Зависимости/инструменты:** XcodeGen, `swift-argument-parser`; Xcode (установлен),
  бесплатный Apple ID (без CloudKit/sandbox-entitlements).
- **Репозиторий:** новый git-репозиторий + GitHub remote; `.gitignore` (исключить
  `*.xcodeproj` генерируемый, `DerivedData`, `.DS_Store`), `README`, `CLAUDE.md`.
- **Ограничение:** единый файл при синхронизации даёт конфликт при одновременной
  правке на двух устройствах (разрешается слиянием по `id`) и оставляет узкое окно
  гонки для одновременного открытия одноразовой ссылки — задокументировано.
