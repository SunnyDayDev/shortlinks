# cli-distribution Specification

## Purpose

Распространение CLI `shortlinks` вместе с приложением: исполняемый файл вкладывается в
бандл `Shortlinks.app`, а приложение делает его доступным из терминала через симлинк в
`~/.local/bin` — с управлением установкой, удалением и статусом доступности.

## Requirements

### Requirement: CLI вложен в бандл приложения

Сборка `Shortlinks.app` SHALL включать исполняемый `shortlinks` внутрь бандла
приложения, так что отдельная установка CLI не требуется. Бинарь SHALL собираться той
же сборкой, что и приложение, и располагаться по фиксированному вложенному пути
`Contents/Helpers/shortlinks`.

Фиксированный путь вложенного CLI SHALL NOT совпадать с путём главного исполняемого
файла приложения с учётом регистронезависимости файловой системы. В частности, CLI
SHALL NOT располагаться в `Contents/MacOS/`, где его имя (`shortlinks`) на
регистронезависимом томе конфликтует с главным исполняемым файлом `Shortlinks` и
затирает его при сборке.

#### Scenario: CLI присутствует в собранном бандле

- **WHEN** собран таргет `ShortlinksApp`
- **THEN** внутри `Shortlinks.app` по пути `Contents/Helpers/shortlinks` присутствует
  исполняемый файл CLI, и его не нужно собирать или устанавливать отдельно

#### Scenario: CLI не конфликтует с исполняемым файлом приложения

- **WHEN** собран таргет `ShortlinksApp` на регистронезависимом томе (стандартный APFS)
- **THEN** `Contents/MacOS/Shortlinks` остаётся главным исполняемым файлом приложения
  и не подменяется CLI-бинарём, а CLI лежит отдельно в `Contents/Helpers/shortlinks`
- **AND** приложение запускается (валидная подпись бандла)

### Requirement: Установка доступности CLI из приложения

Приложение SHALL предоставлять действие «Установить CLI», которое делает вложенный
`shortlinks` доступным из терминала по `PATH` — создавая симлинк на вложенный бинарь в
пользовательском каталоге `~/.local/bin` (без прав администратора). Если каталог не
существует, приложение SHALL создать его. Действие SHALL быть идемпотентным: повторный
запуск приводит к корректному симлинку без ошибки.

#### Scenario: Первая установка

- **WHEN** пользователь нажимает «Установить CLI», и симлинка ещё нет
- **THEN** создаётся `~/.local/bin/shortlinks`, указывающий на вложенный в бандл бинарь,
  и после этого `shortlinks` запускается из терминала (при наличии каталога в `PATH`)

#### Scenario: Повторная установка идемпотентна

- **WHEN** пользователь нажимает «Установить CLI», и симлинк уже указывает на текущий бандл
- **THEN** действие завершается успешно без ошибки и статус остаётся «установлен»

#### Scenario: Перезапись симлинка на другой бандл

- **WHEN** `~/.local/bin/shortlinks` существует как симлинк, указывающий на другой бандл
  Shortlinks
- **THEN** «Установить CLI» перезаписывает симлинк так, чтобы он указывал на текущий бандл

### Requirement: Подсказка про PATH

Приложение SHALL после установки CLI показывать подсказку с инструкцией, как добавить
каталог `~/.local/bin` в `PATH`, если этот каталог отсутствует в `PATH` пользователя.

#### Scenario: Каталог не в PATH

- **WHEN** CLI установлен, но `~/.local/bin` отсутствует в `PATH`
- **THEN** приложение показывает подсказку, как добавить `~/.local/bin` в `PATH`

#### Scenario: Каталог уже в PATH

- **WHEN** CLI установлен и `~/.local/bin` уже присутствует в `PATH`
- **THEN** подсказка про `PATH` не показывается

### Requirement: Предложение установки при первом запуске

Приложение SHALL при первом запуске, если CLI ещё не установлен, предлагать пользователю
установить CLI (онбординг) с действиями «Установить» и «Не сейчас». Предложение SHALL
показываться не более одного раза: после выбора любого из вариантов приложение SHALL
запомнить, что онбординг пройден, и не показывать предложение при последующих запусках.
Приложение SHALL NOT показывать предложение, если CLI уже установлен.

#### Scenario: Первый запуск без установленного CLI

- **WHEN** приложение запускается впервые и CLI не установлен
- **THEN** показывается предложение установить CLI с действиями «Установить» и «Не сейчас»

#### Scenario: Установка из онбординга

- **WHEN** пользователь в предложении выбирает «Установить»
- **THEN** выполняется установка CLI (как из Настроек) и онбординг помечается пройденным

#### Scenario: Отказ из онбординга

- **WHEN** пользователь в предложении выбирает «Не сейчас»
- **THEN** предложение закрывается, онбординг помечается пройденным и больше не показывается

#### Scenario: Повторный запуск не показывает предложение

- **WHEN** приложение запускается, и онбординг уже пройден (или CLI уже установлен)
- **THEN** предложение установить CLI не показывается

### Requirement: Удаление доступности CLI

Приложение SHALL предоставлять действие «Удалить CLI», которое удаляет симлинк
`~/.local/bin/shortlinks`, если он указывает на бандл Shortlinks. Действие SHALL быть
безопасным: оно не удаляет посторонний файл, не являющийся симлинком на Shortlinks.

#### Scenario: Удаление установленного CLI

- **WHEN** пользователь нажимает «Удалить CLI», и симлинк указывает на бандл Shortlinks
- **THEN** симлинк удаляется и статус становится «не установлен»

#### Scenario: Защита постороннего файла

- **WHEN** по пути `~/.local/bin/shortlinks` лежит обычный файл или симлинк не на
  Shortlinks
- **THEN** «Удалить CLI» не удаляет этот файл и сообщает, что путь занят посторонним
  объектом

### Requirement: Отображение статуса установки CLI

Приложение SHALL отображать актуальный статус доступности CLI в одном из состояний:
`установлен` (симлинк указывает на текущий бандл), `не установлен` (симлинка нет),
`конфликт` (по пути посторонний объект или симлинк на другой бандл). Когда CLI
установлен, приложение SHALL показывать путь, по которому доступна команда.

#### Scenario: Статус «установлен»

- **WHEN** `~/.local/bin/shortlinks` — симлинк на вложенный бинарь текущего бандла
- **THEN** приложение показывает статус «установлен» и путь `~/.local/bin/shortlinks`

#### Scenario: Статус «не установлен»

- **WHEN** симлинка `~/.local/bin/shortlinks` нет
- **THEN** приложение показывает статус «не установлен» и предлагает действие «Установить CLI»

#### Scenario: Статус «конфликт»

- **WHEN** по пути `~/.local/bin/shortlinks` посторонний объект или симлинк на другой бандл
- **THEN** приложение показывает статус «конфликт» и поясняет причину
